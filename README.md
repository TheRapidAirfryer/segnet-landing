# SEGNET · Landing page

Propuesta 1: página única (landing) para SEGNET, empresa de redes, telecomunicaciones y seguridad electrónica en Honduras.

Secciones: inicio, servicios integrales (Conectar, Proteger, Mantener), cómo trabajamos, mantenimiento, contacto con formulario que abre WhatsApp con el mensaje listo.

## Uso

```bash
npm install
npm run dev      # desarrollo
npm run build    # versión final en dist/
```

En Vercel se detecta como proyecto Vite sin configuración extra.
